# Nostalgia Mode music

Drop tracks here as `.ogg` (preferred), `.mp3`, or `.wav`. They appear in the
Nostalgia Mode music player, in filename order. The track name shown is the
filename with the extension stripped and underscores/dashes turned to spaces, so
name them how you want them read, e.g.:

    01_crack_intro.ogg   ->  "01 crack intro"
    keygen_theme.ogg     ->  "keygen theme"

Keygen/demoscene chiptune fits the aesthetic. CC0 / royalty-free only. Any number
of tracks; they form the playlist.
